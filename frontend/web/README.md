# Sentinel Pulse — local demo

A read-only Mission Control viewer for Sentinel Pulse, Utkrishta 2026 Challenge 2. The bundled run is generated by the repository CLI from `public/demo/stream.csv`, a synthetic 120-point fixture. Its truth windows are hand-authored synthetic smoke labels. The provisional metric is software-wiring evidence only; it is not an official score or NAB result.

## Rebuild the bundled demo artifacts

From the repository root on Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe scripts\build_demo_artifacts.py
```

This reruns the canonical synthetic CSV through the checked-in detector and provisional evaluator. It rewrites only `predictions.jsonl`, `run.json`, and `evaluation.json` in the demo directory.

## Start the UI

```powershell
cd frontend/web
npm install
npm run dev
```

Open the local Vite URL. For a distributable bundle, run `npm run build`. The viewer reads saved artifacts; it does not perform inference.

## Demo scope

The viewer shows the saved detector trace, causal replay, numerical evidence, provisional event-window scoring, and run hashes. Missing comparison or timing statistics show as `N/A`; no candidate is marked as a winner without a recorded selection.

The organizer starter pack, authorized labels, official scorer/output schema, and timestamp/cadence answers have not been supplied in the repository. Official-data EDA, final model selection, and submission validation remain blocked. Never relabel the bundled fixture as official data.
